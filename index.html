JavaScript Reference Guide

1. Introduction to JS

JavaScript is a High-level, Dynamically-typed, and Interpreted programming language.

High Level

Easy for humans to understand and write. Memory management is handled automatically. Example: Using simple keywords like if (x > 10) { ... } else { ... }.

Dynamically-typed

Smart enough to understand data types automatically without explicitly declaring them. Types can change at runtime. Example:

let num = 5; // Automatically treated as a Number (Not a String)

Interpreted

The code is executed line-by-line (synchronously) by the browser's JS engine, rather than requiring a separate compilation step beforehand.

2. Variables

Variables are containers for storing data values. JS uses three main keywords to declare them:

1. var

The older way to declare variables. It is function-scoped and can be re-declared and updated.

var x = 10; var x = 20; // Allowed: Re-declared without errors

2. let

The modern way to declare variables. It is block-scoped (lives only inside {}) and can be updated, but cannot be re-declared in the same scope.

let score = 90; score = 95; // Allowed: Updated value // let score = 100; // Error: Cannot re-declare

3. const

Short for constant. It is block-scoped and cannot be updated or re-declared. It must be initialized when declared.

const PI = 3.14159; // PI = 3; // Error: Assignment to constant variable

3. Data Types

Data types specify the classification of data that a variable can hold in JavaScript. They are broadly divided into Primitive and Non-Primitive types.

1. String

Represents textual data. Must be wrapped in single or double quotes.

let name = "Noor"; let city = 'Delhi';

2. Number

Represents both integer and floating-point (decimal) numbers.

let age = 25; let price = 99.99;

3. Boolean

Represents a logical entity and can have only two values: true or false.

let isJsFun = true; let isGraduated = false;

4. Undefined

A variable that has been declared but has not yet been assigned a value.

let userData; console.log(userData); // Outputs: undefined

5. Null

Represents the intentional absence of any object value.

let emptyValue = null;

6. Object (Non-Primitive)

Used to store collections of data and more complex entities as key-value pairs.

let student = { firstName: "Noor", age: 22, isPassed: true };

4. Type Conversion (Coercion)

Converting a value from one data type to another is called type conversion. JavaScript does this automatically (implicit coercion) or manually (explicit conversion) using built-in functions.

1. Implicit Conversion (Automatic)

JavaScript automatically converts types when you mix them with operators. This can lead to surprising results, so be careful.

let result1 = "5" + 2; // Outputs: "52" (String wins in +) let result2 = "5" - 2; // Outputs: 3 (Minus forces Number) let result3 = "5" * "2"; // Outputs: 10 (Multiplication forces Number) let result4 = true + 1; // Outputs: 2 (true becomes 1)

2. Explicit Conversion to String

Use String() or toString() to force a value into a string.

let num = 100; console.log(String(num)); // Outputs: "100" console.log(String(true)); // Outputs: "true" console.log( (250).toString()); // Outputs: "250"

3. Explicit Conversion to Number

Use Number(), parseInt(), or parseFloat() to convert strings into numbers.

console.log(Number("42")); // Outputs: 42 console.log(Number("3.14")); // Outputs: 3.14 console.log(Number("Hello")); // Outputs: NaN (Not a Number) console.log(parseInt("42px")); // Outputs: 42 (Stops at first non-number) console.log(parseFloat("3.14 inches")); // Outputs: 3.14

4. Explicit Conversion to Boolean

Use Boolean() to convert any value to true or false.

console.log(Boolean(0)); // Outputs: false console.log(Boolean(1)); // Outputs: true console.log(Boolean("")); // Outputs: false console.log(Boolean("Hello")); // Outputs: true console.log(Boolean(null)); // Outputs: false

5. Type Checking (typeof)

The typeof operator tells you which data type a value is.

console.log(typeof "Hello"); // Outputs: "string" console.log(typeof 42); // Outputs: "number" console.log(typeof true); // Outputs: "boolean" console.log(typeof { name: "Noor" }); // Outputs: "object" console.log(typeof [1, 2, 3]); // Outputs: "object" (Arrays are objects!) console.log(typeof null); // Outputs: "object" (Historical bug)

5. Truthy & Falsy Values

Every value in JavaScript can be converted to a boolean. Values that behave like false inside a condition are called Falsy, and everything else is called Truthy.

1. The 5 Falsy Values

There are exactly 5 falsy values. Everything else is truthy.

if (0) {} // Falsy — 0 if ("") {} // Falsy — empty string if (null) {} // Falsy if (undefined) {} // Falsy if (NaN) {} // Falsy — Not a Number

2. Common Truthy Values

All other values are truthy, including the ones people often expect to be falsy.

if (1) {} // Truthy — any non-zero number if ("0") {} // Truthy — non-empty string if ([]) {} // Truthy — empty ARRAY (trap!) if ({}) {} // Truthy — empty OBJECT (trap!) if ("Hello") {} // Truthy — any non-empty string

3. Using Truthy & Falsy in Practice

This is extremely useful for default values and validation.

let username = ""; // If username is falsy, use "Guest" let displayName = username || "Guest"; // Outputs: "Guest" let price = 0; // 0 is falsy, so default applies let finalPrice = price || 10; // Outputs: 10

6. Operators

1. Arithmetic Operators

Used to perform mathematical calculations.

let sum = 10 + 5; // Addition (+) -> 15 let diff = 10 - 5; // Subtraction (-) -> 5 let product = 10 * 5; // Multiplication (*) -> 50 let quotient = 10 / 5; // Division (/) -> 2 let remainder = 10 % 3; // Modulus (%) -> 1

2. Assignment Operators

Used to assign values to variables.

let x = 10; // Simple assignment (=) x += 5; // Equivalent to: x = x + 5 (Result: 15) x -= 3; // Equivalent to: x = x - 3 (Result: 12)

3. Comparison Operators

Used to compare two values and return a boolean (true/false).

5 == "5"; // True (Compares values only) 5 === "5"; // False (Strict: Compares both value and data type) 10 > 5; // True (Greater than) 10 != 5; // True (Not equal to)

4. Logical Operators

Used to determine the logic between variables or values.

// Logical AND (&&): Both conditions must be true -> (5 > 3 && 10 > 20) returns false // Logical OR (||): At least one condition must be true -> (5 > 3 || 10 > 20) returns true // Logical NOT (!): Reverses the boolean result -> !(5 > 3) returns false

5. Ternary (Conditional) Operator

Acts as a shortcut for an if...else statement.

Syntax: condition ? value_if_true : value_if_false;

let userAge = 18; let status = (userAge >= 18) ? "Adult" : "Minor"; console.log(status); // Outputs: "Adult"

7. Conditional Statements

Used to execute different actions based on different conditions.

1. if Statement

Executes a block of code if a specified condition is true.

let age = 20; if (age >= 18) { console.log("You can vote."); }

2. if...else Statement

Executes a block of code if the condition is true, and another block if it is false.

let isRaining = false; if (isRaining) { console.log("Take an umbrella."); } else { console.log("Enjoy the sunny day!"); }

3. Else-if Ladder

Used to specify a new condition if the first condition is false.

let marks = 75; if (marks >= 90) { console.log("Grade: A+"); } else if (marks >= 75) { console.log("Grade: A"); // Executes here } else { console.log("Grade: F"); }

4. Switch Statement

Used to select one of many code blocks to be executed. Note: break terminates the switch block, and default specifies the code to run if there is no case match.

let dayNumber = 2; let dayName; switch (dayNumber) { case 1: dayName = "Monday"; break; case 2: dayName = "Tuesday"; break; // Matches here default: dayName = "Invalid Day"; }

8. Loops

Loops are used to run the same block of code over and over again, as long as a specified condition is met.

1. for Loop

Loops through a block of code a specified number of times.

Syntax: for (initialization; condition; increment/decrement)

for (let i = 1; i <= 5; i++) { console.log("Number: " + i); }

2. while Loop

Loops through a block of code as long as a specified condition is true.

let count = 1; while (count <= 3) { console.log("Count is: " + count); count++; // Essential to avoid infinite loop }

3. do...while Loop

This loop will execute the code block once before checking if the condition is true, then it will repeat the loop as long as the condition is true.

let x = 10; do { console.log("Runs at least once!"); x++; } while (x < 5);

4. for...of Loop

Loops through the values of an iterable object (like an Array or String).

let fruits = ["Apple", "Banana", "Mango"]; for (let fruit of fruits) { console.log(fruit); }

5. for...in Loop

Loops through the properties (Keys) of an Object.

let car = { brand: "Tata", model: "Nexon", year: 2024 }; for (let key in car) { console.log(key + ": " + car[key]); }

9. Functions

A function is a reusable block of code designed to perform a specific task. You define it once and can call (invoke) it multiple times. Functions help avoid code repetition.

1. Function Declaration

The traditional way to define a function using the function keyword. It gets hoisted (can be called before it is defined in the code).

function sayHello() { console.log("Hello, Welcome to JavaScript!"); } sayHello(); // Calling the function

2. Function with Parameters

Parameters act as placeholders for values that you pass into the function when calling it.

function greetUser(name) { console.log("Hello, " + name + "! How are you?"); } greetUser("Noor"); // Outputs: Hello, Noor! How are you?

3. Function with Multiple Parameters

You can pass multiple values separated by commas.

function addNumbers(num1, num2) { console.log("Sum is: " + (num1 + num2)); } addNumbers(10, 20); // Outputs: Sum is: 30

4. Function with Return Value

The return statement sends a value back to where the function was called. The function stops executing when it hits return.

function multiply(a, b) { return a * b; // Returns the result } let result = multiply(5, 4); console.log("Multiplication Result: " + result); // Outputs: 20

5. Function Expression

Storing an anonymous function inside a variable. It is NOT hoisted — you must define it before calling.

const sayBye = function() { console.log("Goodbye! See you later."); } sayBye(); // Calling via variable name

6. Arrow Function (ES6)

A shorter, modern syntax for writing functions. It does not have its own this context. Note: If there is only one parameter, parentheses are optional. If there is only one return statement, curly braces and return keyword are optional.

// Full syntax const square = (num) => { return num * num; }; console.log(square(6)); // Outputs: 36 // Short syntax (implicit return) const doubleIt = (n) => n * 2; console.log(doubleIt(7)); // Outputs: 14

10. Arrays

An array is a single variable used to store multiple values in an ordered list. Arrays are zero-indexed, meaning the first element is at position 0. Arrays can hold mixed data types.

1. Creating an Array

Using square brackets [] is the most common way (Array Literal).

let colors = ["Red", "Green", "Blue"]; let mixed = ["Apple", 25, true, null]; // Mixed data types allowed

2. Accessing Elements by Index

Access elements using their index number inside square brackets.

let fruits = ["Mango", "Banana", "Grapes"]; console.log(fruits[0]); // Outputs: "Mango" (First element) console.log(fruits[2]); // Outputs: "Grapes" (Third element)

3. Modifying Elements

You can change an element's value by assigning a new value to a specific index.

let cars = ["Honda", "Toyota", "Ford"]; cars[1] = "BMW"; // Changing "Toyota" to "BMW" console.log(cars); // Outputs: ["Honda", "BMW", "Ford"]

4. Array Length Property

The .length property returns the total number of elements in the array.

let numbers = [10, 20, 30, 40, 50]; console.log(numbers.length); // Outputs: 5

5. Adding Elements

push() adds to the end. unshift() adds to the beginning.

let animals = ["Dog", "Cat"]; animals.push("Lion"); // Adds to end -> ["Dog", "Cat", "Lion"] animals.unshift("Bird"); // Adds to start -> ["Bird", "Dog", "Cat", "Lion"] console.log(animals);

6. Removing Elements

pop() removes from the end. shift() removes from the beginning.

let items = ["Pen", "Book", "Eraser", "Scale"]; items.pop(); // Removes "Scale" from end items.shift(); // Removes "Pen" from start console.log(items); // Outputs: ["Book", "Eraser"]

11. Objects

An object is a collection of related data stored as key-value pairs. The key (also called property name) is always a string, and the value can be any data type (string, number, array, function, or even another object). Objects are used to represent real-world entities.

1. Creating an Object (Object Literal)

The most common way — using curly braces {}.

let student = { name: "Noor", age: 22, course: "Web Development", isGraduated: false };

2. Accessing Properties (Dot Notation)

Use a dot . followed by the property name. Most common and easiest way.

let car = { brand: "Tata", model: "Nexon" }; console.log(car.brand); // Outputs: "Tata" console.log(car.model); // Outputs: "Nexon"

3. Accessing Properties (Bracket Notation)

Use square brackets with the property name as a string. Useful when property names have spaces or are stored in a variable.

let user = { firstName: "Rahul", "last name": "Sharma" }; console.log(user["firstName"]); // Outputs: "Rahul" console.log(user["last name"]); // Outputs: "Sharma" (Cannot use dot notation here)

4. Modifying Properties

Assign a new value to an existing key using dot or bracket notation.

let phone = { brand: "Samsung", price: 25000 }; phone.price = 22000; // Updated price console.log(phone.price); // Outputs: 22000

5. Adding New Properties

Simply assign a value to a new key that doesn't exist yet.

let laptop = { brand: "Dell", ram: "8GB" }; laptop.storage = "512GB"; // Adding new property laptop.color = "Black"; // Adding another new property console.log(laptop); // Outputs: { brand: "Dell", ram: "8GB", storage: "512GB", color: "Black" }

6. Deleting Properties

Use the delete keyword to remove a property entirely from the object.

let employee = { name: "Priya", dept: "HR", salary: 40000 }; delete employee.salary; // Removes the salary property console.log(employee); // Outputs: { name: "Priya", dept: "HR" }

7. Object with Method (Function inside Object)

A method is a function stored as a property inside an object. It allows the object to perform actions using its own data. Use this keyword to refer to the current object's properties inside the method.

let person = { name: "Amit", age: 30, introduce: function() { console.log("Hi, I am " + this.name + " and I am " + this.age + " years old."); } }; person.introduce(); // Outputs: Hi, I am Amit and I am 30 years old.

12. Array Methods

Array methods are built-in functions that you can call on arrays to perform common operations like searching, transforming, filtering, and sorting — without writing manual loops.

1. indexOf()

Returns the first index at which a given element is found. Returns -1 if the element is not present.

let fruits = ["Apple", "Mango", "Banana", "Mango"]; console.log(fruits.indexOf("Mango")); // Outputs: 1 (first occurrence) console.log(fruits.indexOf("Grapes")); // Outputs: -1 (not found)

2. includes()

Returns true if the array contains the specified element, otherwise false.

let colors = ["Red", "Green", "Blue"]; console.log(colors.includes("Green")); // Outputs: true console.log(colors.includes("Yellow")); // Outputs: false

3. join()

Joins all elements of an array into a single string, separated by a specified separator (default is comma).

let words = ["Hello", "World", "JavaScript"]; console.log(words.join()); // Outputs: "Hello,World,JavaScript" console.log(words.join(" - ")); // Outputs: "Hello - World - JavaScript" console.log(words.join(" ")); // Outputs: "Hello World JavaScript"

4. slice()

Returns a shallow copy of a portion of the array into a new array. Note: It does NOT modify the original array. Parameters are (start, end) — end index is excluded.

let nums = [10, 20, 30, 40, 50]; let sliced = nums.slice(1, 4); // Index 1 to 3 (4 is excluded) console.log(sliced); // Outputs: [20, 30, 40] console.log(nums); // Original unchanged: [10, 20, 30, 40, 50]

5. splice()

Used to add, remove, or replace elements in an array. Note: It MODIFIES the original array. Parameters: splice(startIndex, deleteCount, item1ToAdd, item2ToAdd, ...).

let arr = ["A", "B", "C", "D", "E"]; // Remove 2 elements starting from index 1 let removed = arr.splice(1, 2); console.log(removed); // Outputs: ["B", "C"] (removed items) console.log(arr); // Outputs: ["A", "D", "E"] (original modified)

6. concat()

Merges two or more arrays and returns a new array. Does NOT change the original arrays.

let arr1 = [1, 2, 3]; let arr2 = [4, 5, 6]; let merged = arr1.concat(arr2); console.log(merged); // Outputs: [1, 2, 3, 4, 5, 6] console.log(arr1); // Outputs: [1, 2, 3] (unchanged)

7. reverse()

Reverses the order of elements in the array. Warning: It MODIFIES the original array.

let letters = ["A", "B", "C", "D"]; letters.reverse(); console.log(letters); // Outputs: ["D", "C", "B", "A"]

8. sort()

Sorts the elements of an array in-place (modifies original). By default, it sorts elements as strings alphabetically, which can cause issues with numbers.

// String sorting (default) let names = ["Zara", "Noor", "Amit"]; names.sort(); console.log(names); // Outputs: ["Amit", "Noor", "Zara"] // Number sorting (needs compare function) let numArr = [40, 100, 1, 5, 25]; numArr.sort(function(a, b) { return a - b; }); // Ascending console.log(numArr); // Outputs: [1, 5, 25, 40, 100]

9. push() & pop()

push() adds one or more elements to the end and returns the new length. pop() removes the last element and returns it.

let stack = [10, 20]; let newLength = stack.push(30, 40); // Adds to end console.log(newLength); // Outputs: 4 let lastItem = stack.pop(); // Removes from end console.log(lastItem); // Outputs: 40 console.log(stack); // Outputs: [10, 20, 30]

10. shift() & unshift()

shift() removes the first element and returns it. unshift() adds elements to the beginning and returns the new length.

let queue = ["B", "C", "D"]; queue.unshift("A"); // Adds "A" to start -> ["A", "B", "C", "D"] let first = queue.shift(); // Removes "A" from start console.log(first); // Outputs: "A" console.log(queue); // Outputs: ["B", "C", "D"]

11. map()

Creates a new array by applying a function to every element of the original array. Does NOT modify the original. Commonly used for transforming data.

let prices = [100, 200, 300]; let discounted = prices.map(function(price) { return price - 20; // Apply 20 rupees discount }); console.log(discounted); // Outputs: [80, 180, 280] console.log(prices); // Outputs: [100, 200, 300] (unchanged)

12. filter()

Creates a new array containing only those elements that pass a test (condition returns true). Does NOT modify the original.

let ages = [12, 18, 25, 8, 30, 16]; let adults = ages.filter(function(age) { return age >= 18; // Keep only 18 or above }); console.log(adults); // Outputs: [18, 25, 30] console.log(ages); // Outputs: [12, 18, 25, 8, 30, 16] (unchanged)

13. reduce()

Reduces the entire array to a single value (like a sum, product, or merged string). It takes a callback with an accumulator and a current value.

let numbers = [1, 2, 3, 4, 5]; let total = numbers.reduce(function(accumulator, currentValue) { return accumulator + currentValue; }, 0); // 0 is the initial value of accumulator console.log(total); // Outputs: 15 (1+2+3+4+5)

14. find()

Returns the first element that satisfies the provided condition. Returns undefined if no element matches.

let users = [ { id: 1, name: "Noor" }, { id: 2, name: "Rahul" }, { id: 3, name: "Priya" } ]; let found = users.find(function(user) { return user.id === 2; }); console.log(found); // Outputs: { id: 2, name: "Rahul" }

15. findIndex()

Returns the index of the first element that satisfies the condition. Returns -1 if not found.

let scores = [45, 80, 55, 90, 60]; let index = scores.findIndex(function(score) { return score > 85; }); console.log(index); // Outputs: 3 (because 90 is at index 3)

16. forEach()

Executes a provided function once for each array element. It does NOT return a new array (returns undefined). Used mainly for performing side effects like logging.

let cities = ["Delhi", "Mumbai", "Chennai"]; cities.forEach(function(city, index) { console.log(index + ": " + city); }); // Outputs: // 0: Delhi // 1: Mumbai // 2: Chennai

17. every()

Returns true if ALL elements pass the test condition. Returns false if even one element fails.

let marks = [80, 85, 90, 78, 88]; let allPassed = marks.every(function(mark) { return mark >= 75; // Check if everyone scored 75+ }); console.log(allPassed); // Outputs: true

18. some()

Returns true if AT LEAST ONE element passes the test condition. Opposite of every().

let ages = [12, 15, 22, 10]; let hasAdult = ages.some(function(age) { return age >= 18; }); console.log(hasAdult); // Outputs: true (because 22 is present)

19. flat()

Flattens a nested array (array inside array) into a single flat array. Takes an optional depth argument (default is 1).

let nested = [1, [2, 3], [4, [5, 6]]]; console.log(nested.flat()); // Outputs: [1, 2, 3, 4, [5, 6]] (depth 1) console.log(nested.flat(Infinity)); // Outputs: [1, 2, 3, 4, 5, 6] (fully flat)

20. Array.isArray()

A static method used to check if a given value is an array. Returns true or false.

let arr = [1, 2, 3]; let obj = { name: "Noor" }; console.log(Array.isArray(arr)); // Outputs: true console.log(Array.isArray(obj)); // Outputs: false

13. Object Methods

Object methods are built-in functions that help you work with objects — like getting keys, values, converting objects to arrays, and merging objects.

1. Object.keys()

Returns an array of all keys (property names) of the object.

let student = { name: "Noor", age: 22, city: "Delhi" }; let keys = Object.keys(student); console.log(keys); // Outputs: ["name", "age", "city"]

2. Object.values()

Returns an array of all values of the object's properties.

let car = { brand: "Tata", model: "Nexon", year: 2024 }; let vals = Object.values(car); console.log(vals); // Outputs: ["Tata", "Nexon", 2024]

3. Object.entries()

Returns an array of arrays, where each inner array is a [key, value] pair. Useful when you want to loop through both keys and values together.

let product = { name: "Laptop", price: 50000, inStock: true }; let entries = Object.entries(product); console.log(entries); // Outputs: [ ["name", "Laptop"], ["price", 50000], ["inStock", true] ]

4. Object.hasOwnProperty()

Checks if the object has a specific property as its own (not inherited). Returns true or false.

let user = { name: "Amit", email: "amit@mail.com" }; console.log(user.hasOwnProperty("name")); // Outputs: true console.log(user.hasOwnProperty("phone")); // Outputs: false

5. Object.assign()

Copies properties from one or more source objects into a target object. Modifies the target object and also returns it.

let target = { a: 1, b: 2 }; let source = { b: 3, c: 4 }; // 'b' will overwrite target's 'b' let result = Object.assign(target, source); console.log(result); // Outputs: { a: 1, b: 3, c: 4 } console.log(target); // Outputs: { a: 1, b: 3, c: 4 } (target is modified)

6. Object.freeze()

Makes an object completely immutable — you cannot add, remove, or modify any properties. Returns the frozen object.

let config = { theme: "dark", fontSize: 14 }; Object.freeze(config); config.theme = "light"; // Silently fails (no error in non-strict mode) config.newProp = "test"; // Silently fails console.log(config); // Outputs: { theme: "dark", fontSize: 14 } (unchanged)

7. Object.seal()

Prevents adding new properties or removing existing ones, but allows modifying existing property values.

let data = { name: "Rahul", score: 85 }; Object.seal(data); data.score = 90; // Allowed: modifying existing property data.city = "Mumbai"; // Silently fails: cannot add new property delete data.name; // Silently fails: cannot delete console.log(data); // Outputs: { name: "Rahul", score: 90 }

8. Object.keys().length

Objects don't have a .length property directly. To find how many properties an object has, use Object.keys(obj).length.

let employee = { id: 1, name: "Priya", dept: "HR", salary: 40000 }; let propCount = Object.keys(employee).length; console.log(propCount); // Outputs: 4

14. String Methods

String methods are built-in functions that help you manipulate, search, extract, and transform text. Important: Strings are immutable in JavaScript — no method changes the original string; they always return a new string.

1. length (Property)

Not a method, but a property. Returns the total number of characters in the string (spaces are also counted).

let str = "Hello World"; console.log(str.length); // Outputs: 11

2. toUpperCase()

Converts the entire string to uppercase letters.

let name = "noor"; console.log(name.toUpperCase()); // Outputs: "NOOR"

3. toLowerCase()

Converts the entire string to lowercase letters.

let city = "DELHI"; console.log(city.toLowerCase()); // Outputs: "delhi"

4. trim()

Removes whitespace (spaces, tabs, newlines) from both ends of the string. Does NOT remove spaces from the middle.

let messy = " Hello World "; console.log(messy.trim()); // Outputs: "Hello World"

5. trimStart()

Removes whitespace only from the beginning (left side) of the string.

let text = " Hello World"; console.log(text.trimStart()); // Outputs: "Hello World"

6. trimEnd()

Removes whitespace only from the end (right side) of the string.

let text = "Hello World "; console.log(text.trimEnd()); // Outputs: "Hello World"

7. includes()

Checks if a substring exists inside the string. Returns true or false. It is case-sensitive.

let sentence = "I love JavaScript"; console.log(sentence.includes("love")); // Outputs: true console.log(sentence.includes("Love")); // Outputs: false (case-sensitive)

8. indexOf()

Returns the first index (position) where the specified substring is found. Returns -1 if not found.

let msg = "Hello World Hello"; console.log(msg.indexOf("Hello")); // Outputs: 0 (first occurrence) console.log(msg.indexOf("World")); // Outputs: 6 console.log(msg.indexOf("Bye")); // Outputs: -1 (not found)

9. lastIndexOf()

Same as indexOf(), but searches from the end and returns the last occurrence's index.

let msg = "Hello World Hello"; console.log(msg.lastIndexOf("Hello")); // Outputs: 12 (second "Hello")

10. startsWith()

Checks if the string starts with the specified substring. Returns true or false.

let url = "https://google.com"; console.log(url.startsWith("https")); // Outputs: true console.log(url.startsWith("http")); // Outputs: true ("https" starts with "http")

11. endsWith()

Checks if the string ends with the specified substring. Returns true or false.

let filename = "photo.jpg"; console.log(filename.endsWith(".jpg")); // Outputs: true console.log(filename.endsWith(".png")); // Outputs: false

12. charAt()

Returns the character at a specific index. If the index is out of range, it returns an empty string.

let word = "JavaScript"; console.log(word.charAt(0)); // Outputs: "J" console.log(word.charAt(4)); // Outputs: "S"

13. charCodeAt()

Returns the Unicode (ASCII) number of the character at a given index.

let letter = "A"; console.log(letter.charCodeAt(0)); // Outputs: 65 console.log("a".charCodeAt(0)); // Outputs: 97

14. slice(start, end)

Extracts a portion of the string and returns it as a new string. The end index is excluded. Negative values count from the end.

let str = "Hello World"; console.log(str.slice(0, 5)); // Outputs: "Hello" (index 0 to 4) console.log(str.slice(6)); // Outputs: "World" (from index 6 to end) console.log(str.slice(-5)); // Outputs: "World" (last 5 characters)

15. substring(start, end)

Same as slice() but does NOT accept negative indices. If you pass a negative number, it treats it as 0.

let str = "Hello World"; console.log(str.substring(0, 5)); // Outputs: "Hello" console.log(str.substring(6, 11)); // Outputs: "World" console.log(str.substring(-3)); // Outputs: "Hello World" (negative treated as 0)

16. replace()

Replaces the first occurrence of a substring with another string. It is case-sensitive and does NOT modify the original string.

let text = "I love cats. Cats are cute."; console.log(text.replace("cats", "dogs")); // Outputs: "I love dogs. Cats are cute." (only first "cats" replaced)

17. replaceAll()

Replaces ALL occurrences of a substring. (ES2021 feature — works in modern browsers).

let text = "I love cats. Cats are cute."; console.log(text.replaceAll("cats", "dogs").replaceAll("Cats", "Dogs")); // Outputs: "I love dogs. Dogs are cute."

18. split()

Splits a string into an array of substrings based on a specified separator. Very useful for breaking strings into words or parts.

let csv = "Red,Green,Blue,Yellow"; console.log(csv.split(",")); // Outputs: ["Red", "Green", "Blue", "Yellow"] let sentence = "Hello World JavaScript"; console.log(sentence.split(" ")); // Outputs: ["Hello", "World", "JavaScript"] let word = "JavaScript"; console.log(word.split("")); // Outputs: ["J","a","v","a","S","c","r","i","p","t"]

19. repeat()

Returns a new string with the original string repeated a specified number of times.

let dash = "-"; console.log(dash.repeat(10)); // Outputs: "----------" let ha = "Ha"; console.log(ha.repeat(3)); // Outputs: "HaHaHa"

20. concat()

Joins two or more strings together and returns a new string. Same as using the + operator.

let first = "Hello"; let second = "World"; console.log(first.concat(" ", second)); // Outputs: "Hello World" console.log(first.concat(" ", second, "!")); // Outputs: "Hello World!"

21. padStart()

Pads the string from the start with a specified character until it reaches the target length. Useful for formatting numbers.

let num = "5"; console.log(num.padStart(3, "0")); // Outputs: "005" let pin = "123"; console.log(pin.padStart(6, "*")); // Outputs: "***123"

22. padEnd()

Pads the string from the end with a specified character until it reaches the target length.

let name = "Noor"; console.log(name.padEnd(10, ".")); // Outputs: "Noor......" let price = "99"; console.log(price.padEnd(6, " ")); // Outputs: "99 "

23. match()

Searches the string using a regular expression (RegExp) and returns an array of matches, or null if no match is found.

let text = "Call me at 9876543210 or 9123456789"; let numbers = text.match(/\d{10}/g); // Find all 10-digit numbers console.log(numbers); // Outputs: ["9876543210", "9123456789"]

15. Number Methods

Numbers have built-in methods to convert, format, and round values. They are useful when dealing with prices, calculations, and user input.

1. toString()

Converts a number into a string.

let age = 25; console.log(age.toString()); // Outputs: "25" console.log((100).toString()); // Outputs: "100" console.log(typeof (50).toString()); // Outputs: "string"

2. toFixed()

Rounds a number to a fixed number of decimal places and returns it as a string. Perfect for showing prices.

let price = 19.995; console.log(price.toFixed(2)); // Outputs: "20.00" console.log(price.toFixed(1)); // Outputs: "20.0" console.log(price.toFixed(0)); // Outputs: "20"

3. toPrecision()

Returns a string with a specified total number of digits (including the decimal part).

let num = 123.456; console.log(num.toPrecision(4)); // Outputs: "123.5" console.log(num.toPrecision(2)); // Outputs: "1.2e+2" console.log(num.toPrecision(6)); // Outputs: "123.456"

4. parseInt()

Parses a string and returns a whole number. It stops reading at the first non-numeric character.

console.log(parseInt("42px")); // Outputs: 42 console.log(parseInt("10 students")); // Outputs: 10 console.log(parseInt("abc")); // Outputs: NaN console.log(parseInt("3.99")); // Outputs: 3 (Whole number only)

5. parseFloat()

Parses a string and returns a decimal (floating point) number.

console.log(parseFloat("3.99")); // Outputs: 3.99 console.log(parseFloat("10.5 kg")); // Outputs: 10.5 console.log(parseFloat("abc")); // Outputs: NaN

6. Number.isInteger()

Checks if a value is a whole number. Returns true or false.

console.log(Number.isInteger(10)); // Outputs: true console.log(Number.isInteger(10.5)); // Outputs: false console.log(Number.isInteger("10")); // Outputs: false (String is not a number)

7. NaN (Not a Number)

NaN is returned when a numeric operation fails. Use Number.isNaN() to check for it.

let result = "hello" * 2; console.log(result); // Outputs: NaN console.log(Number.isNaN(result)); // Outputs: true console.log(Number.isNaN(42)); // Outputs: false

16. Math Methods

The Math object provides mathematical functions like rounding, generating random numbers, and finding the highest/lowest values. It is a static object — you never create it, you just call Math.method() directly.

1. Rounding Methods

Math.round() rounds to the nearest integer, Math.ceil() always rounds up, and Math.floor() always rounds down.

console.log(Math.round(4.6)); // Outputs: 5 (Nearest integer) console.log(Math.ceil(4.1)); // Outputs: 5 (Rounds UP) console.log(Math.floor(4.9)); // Outputs: 4 (Rounds DOWN) console.log(Math.trunc(4.9)); // Outputs: 4 (Removes the decimal part)

2. Random Numbers

Math.random() returns a random decimal between 0 (inclusive) and 1 (exclusive). Combine it with Math.floor() to get random integers.

console.log(Math.random()); // Random decimal like 0.5473... // Random integer between 1 and 10 (Formula) let randomInt = Math.floor(Math.random() * 10) + 1; console.log(randomInt);

3. Max, Min, Pow, Sqrt

Common mathematical utilities used daily.

console.log(Math.max(10, 20, 5)); // Outputs: 20 (Highest value) console.log(Math.min(10, 20, 5)); // Outputs: 5 (Lowest value) console.log(Math.pow(2, 3)); // Outputs: 8 (2 raised to power 3) console.log(Math.sqrt(16)); // Outputs: 4 (Square root) console.log(Math.abs(-5)); // Outputs: 5 (Absolute value) console.log(Math.PI); // Outputs: 3.141592653589793

17. Date & Time

The Date object is used to work with dates and times. Create one with new Date() and then call its methods to read parts like year, month, or day.

1. Creating a Date

There are several ways to create a date object.

let now = new Date(); // Current date & time let specific = new Date("2025-01-15"); // From a string let manual = new Date(2025, 0, 15); // Year, Month (0-11!), Day console.log(now); // Outputs: current date/time

2. Getting Date Parts

Extract individual pieces of a date using getter methods.

let today = new Date(); console.log(today.getFullYear()); // e.g., 2025 console.log(today.getMonth()); // 0-11 (January is 0!) console.log(today.getDate()); // Day of month (1-31) console.log(today.getDay()); // Day of week (0=Sunday) console.log(today.getHours()); // 0-23 console.log(today.getMinutes()); // 0-59 console.log(today.getSeconds()); // 0-59

3. Timestamps (getTime)

getTime() returns the number of milliseconds since January 1, 1970. Useful for calculations and unique IDs.

let now = new Date(); console.log(now.getTime()); // Large number like 1767234567890 console.log(Date.now()); // Same, but shorter

4. Formatting Dates

Convert dates into readable strings using built-in methods.

let today = new Date(); console.log(today.toDateString()); // e.g., "Wed Jan 15 2025" console.log(today.toLocaleDateString()); // e.g., "15/1/2025" console.log(today.toLocaleTimeString()); // e.g., "10:30:00 AM" console.log(today.toLocaleString()); // Date + Time combined

18. DOM Manipulation

DOM (Document Object Model) is a tree-like structure created by the browser when an HTML page loads. JavaScript uses the DOM to select, read, modify, add, and remove HTML elements dynamically — without reloading the page. Think of the DOM as JavaScript's "remote control" for the webpage.

1. Selecting Elements

The first step in DOM manipulation is finding the element you want to work with. There are 5 main methods:

// 1. getElementById — Returns a SINGLE element by its ID let heading = document.getElementById("main-title"); // 2. getElementsByClassName — Returns a LIVE HTMLCollection of elements let cards = document.getElementsByClassName("card"); // 3. getElementsByTagName — Returns a LIVE HTMLCollection by tag name let paragraphs = document.getElementsByTagName("p"); // 4. querySelector — Returns the FIRST element matching a CSS selector let firstBtn = document.querySelector(".btn-primary"); // 5. querySelectorAll — Returns a STATIC NodeList of ALL matching elements let allItems = document.querySelectorAll(".list-item");

2. Reading & Changing Content

Once you select an element, you can read or change its content using these properties:

let box = document.getElementById("box"); // innerHTML — Gets/sets the HTML inside (parses HTML tags) box.innerHTML = "<strong>Hello</strong> World"; // textContent — Gets/sets only plain text (ignores/safe from HTML tags) box.textContent = "<strong>Hello</strong> World"; // innerText — Similar to textContent but respects CSS visibility console.log(box.innerText);

3. Changing Attributes

You can get, set, or remove HTML attributes (like src, href, class) using these methods:

let img = document.querySelector("img"); console.log(img.getAttribute("src")); // Read img.setAttribute("src", "new-photo.jpg"); // Set/Change img.removeAttribute("alt"); // Remove // Direct property access (shorter, works for standard attributes) img.src = "another-photo.jpg";

4. Changing Styles

Use the style property to change inline CSS. Property names use camelCase.

let card = document.querySelector(".card"); card.style.backgroundColor = "#f7df1e"; card.style.padding = "20px"; card.style.display = "none"; // Hide element

5. Working with Classes (classList)

classList is the recommended way to manipulate CSS classes instead of inline styles.

let btn = document.querySelector("button"); btn.classList.add("btn-primary", "rounded"); // Add classes btn.classList.remove("rounded"); // Remove class btn.classList.toggle("active"); // Add if missing, remove if present btn.classList.contains("active"); // Returns true/false btn.classList.replace("old-class", "new-class"); // Replace

6. Creating & Adding Elements

You can create brand new elements and insert them into the DOM dynamically.

let newParagraph = document.createElement("p"); newParagraph.textContent = "This is a newly created paragraph."; newParagraph.id = "new-para"; let container = document.getElementById("container"); container.appendChild(newParagraph); // Adds as the LAST child

7. Removing Elements

To remove an element from the DOM completely.

// Modern way (no parent needed) let oldElement = document.querySelector(".outdated"); oldElement.remove(); // Traditional way (needs parent) // parent.removeChild(child);

8. Traversing the DOM

Moving between related elements (parent, children, siblings) in the DOM tree.

let item = document.querySelector(".item"); let parentEl = item.parentElement; // Parent let firstChildEl = item.firstElementChild; // First child let nextEl = item.nextElementSibling; // Next sibling let prevEl = item.previousElementSibling; // Previous sibling

9. Data Attributes (dataset)

Data attributes (data-*) let you store custom info in HTML. Access them via dataset in JS. Note: kebab-case becomes camelCase in JS.

<div id="user" data-userid="101" data-role="admin"></div> let userDiv = document.getElementById("user"); console.log(userDiv.dataset.userid); // "101" userDiv.dataset.status = "online"; // Sets data-status="online"

19. Events & Event Listeners

Events are actions that happen in the browser (like a user clicking a button, typing in an input, or the page finishing loading). addEventListener is the modern way to "listen" for these actions and run JavaScript code when they occur.

1. addEventListener

Attaches a function (callback) to an element that triggers whenever a specific event happens. Syntax: element.addEventListener('event', callbackFunction).

let btn = document.querySelector("#myBtn"); btn.addEventListener("click", function() { alert("Button was clicked!"); });

2. The 'event' Object

When an event occurs, the browser automatically passes an event object to your callback function. It contains useful info like exactly what was clicked (event.target), mouse coordinates, etc.

// Useful for handling multiple buttons with a single listener let allButtons = document.querySelectorAll(".btn"); allButtons.forEach(function(button) { button.addEventListener("click", function(event) { console.log("You clicked:", event.target.textContent); console.log("Tag name:", event.target.tagName); // "BUTTON" }); });

3. Common Events

There are dozens of events. Here are the most frequently used ones:

// Mouse Events // "click" — Clicked once // "dblclick" — Double-clicked // "mouseenter" — Mouse pointer enters the element // "mouseleave" — Mouse pointer leaves the element // Keyboard Events (used on inputs or the whole document) // "keydown" — Key is pressed down // "keyup" — Key is released // Input/Form Events // "input" — Fires every time the value of an input changes // "change" — Fires when user finishes typing and clicks away // "submit" — Fires when a form is submitted

4. Getting Input Values

You can combine Events with DOM Selection to read what a user is typing in real-time.

let inputField = document.querySelector("#myInput"); let displayText = document.querySelector("#display"); inputField.addEventListener("input", function(event) { // event.target.value gives the current text inside the input displayText.textContent = event.target.value; });

5. Preventing Default Behavior

Some elements have built-in browser behavior. For example, clicking a <a> tag refreshes the page, or submitting a <form> reloads the page. Use event.preventDefault() to stop this so you can handle it with JS instead.

let form = document.querySelector("#loginForm"); form.addEventListener("submit", function(event) { event.preventDefault(); // Stops page from reloading! // Now you can grab the data manually let email = document.querySelector("#email").value; console.log("Form submitted with email:", email); });

6. removeEventListener

Removes an event listener that was previously attached. Important: You cannot remove an anonymous function. You must pass the exact same named function reference.

function handleHover() { console.log("Mouse is hovering!"); } let box = document.querySelector(".box"); box.addEventListener("mouseenter", handleHover); // Later, if you want to remove it: box.removeEventListener("mouseenter", handleHover);

20. Error Handling (try...catch...finally)

When JavaScript encounters an error (like calling a method on null or parsing invalid JSON), it stops executing the rest of the script and throws an error in the console. try...catch allows you to "catch" these errors gracefully so your entire app doesn't crash.

1. The try...catch Block

Put the "risky" code inside the try block. If an error occurs, JS immediately jumps to the catch block instead of crashing.

try { // Risky code here let data = JSON.parse("This is not valid JSON"); // Will throw an error } catch (error) { // This block runs ONLY if an error happened in try console.log("An error occurred!"); console.log("Error Name:", error.name); // e.g., "SyntaxError" console.log("Error Message:", error.message); // Explains what went wrong }

2. The finally Block

The finally block runs no matter what — whether the code in try succeeded or failed. It is typically used for cleanup tasks (like hiding a loading spinner).

let isLoading = true; try { let result = 10 / 2; console.log("Result:", result); } catch (error) { console.log("Caught an error."); } finally { // This ALWAYS runs isLoading = false; console.log("Loading finished."); }

3. Throwing Custom Errors

You can manually trigger an error to stop execution if your custom validation fails, using the throw keyword.

function checkAge(age) { if (age < 0) { throw new Error("Age cannot be negative!"); // Custom error thrown } return "Valid age: " + age; } try { console.log(checkAge(-5)); } catch (error) { console.log(error.message); // Outputs: "Age cannot be negative!" }

21. ES6+ Modern Features

ES6 (ECMAScript 2015) brought massive improvements to JavaScript, making code shorter, cleaner, and easier to read. These features are standard in the modern web industry.

1. Template Literals (Backticks `` ` ``)

Instead of using the + operator to concatenate strings, use backticks. They allow you to inject variables directly using ${variableName} (String Interpolation) and write multi-line strings without \n.

let name = "Noor"; let age = 22; // Old way (messy) console.log("Hello, " + name + ". You are " + age + " years old."); // New way (Template Literals - clean) console.log(`Hello, ${name}. You are ${age} years old.`); // Multi-line string let html = ` <div class="card"> <h2>${name}</h2> <p>Age: ${age}</p> </div>`; console.log(html);

2. Destructuring (Arrays & Objects)

A shortcut to unpack values from arrays or properties from objects into distinct variables in a single line.

// Object Destructuring const student = { name: "Rahul", grade: "A", city: "Mumbai" }; const { name, grade, city } = student; // Variables must match object keys console.log(name, grade); // "Rahul" "A" // Array Destructuring (order matters, not name) const colors = ["Red", "Green", "Blue"]; const [firstColor, secondColor, thirdColor] = colors; console.log(secondColor); // "Green" // Renaming while destructuring objects const { name: studentName, grade: studentGrade } = student; console.log(studentName); // "Rahul"

3. Spread Operator (...)

The spread operator ... expands an iterable (like an array or object) into individual elements. It is incredibly useful for cloning and merging.

// Cloning an Array (creates a NEW array, not a reference) const originalArr = [1, 2, 3]; const clonedArr = [...originalArr]; clonedArr.push(4); console.log(originalArr); // [1, 2, 3] (unchanged) // Merging two Arrays const arrA = [1, 2]; const arrB = [3, 4]; const mergedArr = [...arrA, ...arrB]; // [1, 2, 3, 4] // Cloning & Merging Objects const user = { name: "Noor", age: 22 }; const details = { city: "Delhi", country: "India" }; const fullUser = { ...user, ...details }; console.log(fullUser); // { name: "Noor", age: 22, city: "Delhi", country: "India" }

4. Rest Operator (...)

Looks exactly like the spread operator ..., but does the opposite. It packs remaining elements into a single array. It is mostly used in function parameters to accept any number of arguments.

// Function that accepts unlimited numbers function calculateSum(...numbers) { // 'numbers' becomes an array [10, 20, 30] return numbers.reduce((total, num) => total + num, 0); } console.log(calculateSum(10, 20, 30)); // 60 console.log(calculateSum(5, 5)); // 10 // Rest in Array Destructuring const scores = [95, 80, 75, 60, 55]; const [first, second, ...restOfScores] = scores; console.log(first); // 95 console.log(restOfScores); // [75, 60, 55]

5. Default Parameters

Allows you to set default values for function parameters in case the user forgets to pass an argument.

// If 'role' is not passed, it defaults to "Guest" function greetUser(name, role = "Guest") { console.log(`Hello ${name}, your role is ${role}`); } greetUser("Amit", "Admin"); // Outputs: Hello Amit, your role is Admin greetUser("Noor"); // Outputs: Hello Noor, your role is Guest

6. Short Circuit Evaluation (&& and ||)

Beyond simple true/false logic, logical operators can be used to set default values or conditionally run code in a very short syntax.

// || (OR) for setting default fallback values let userName = "" || "Anonymous"; // If left is falsy (empty string), use right console.log(userName); // "Anonymous" // && (AND) for conditional execution (runs right side ONLY if left is true) let isLoggedin = true; isLoggedin && console.log("Welcome to the dashboard!"); // Prints welcome // If isLoggedin was false, the console.log would NOT even run.

22. Classes & OOP (Object-Oriented Programming)

A class is a blueprint for creating objects. OOP lets you organize code into reusable structures with properties (data) and methods (functions). Classes make it easy to create many similar objects.

1. Creating a Class

Use the class keyword. The constructor method runs automatically when you create a new object and sets initial values.

class Student { constructor(name, age) { this.name = name; this.age = age; } } let s1 = new Student("Noor", 22); let s2 = new Student("Rahul", 25); console.log(s1.name); // Outputs: "Noor" console.log(s2.age); // Outputs: 25

2. Class Methods

Methods are functions defined inside the class. They are shared by all objects created from the class.

class Car { constructor(brand, model) { this.brand = brand; this.model = model; } start() { console.log(this.brand + " " + this.model + " is starting!"); } } let myCar = new Car("Tata", "Nexon"); myCar.start(); // Outputs: Tata Nexon is starting!

3. Inheritance (extends)

A class can inherit properties and methods from another class using extends. The child class also gets the parent's methods. Use super() to call the parent's constructor.

class Animal { constructor(name) { this.name = name; } speak() { console.log(this.name + " makes a sound."); } } class Dog extends Animal { constructor(name, breed) { super(name); // Calls parent constructor this.breed = breed; } bark() { console.log(this.name + " barks!"); } } let dog = new Dog("Tommy", "Labrador"); dog.speak(); // Inherited method // Outputs: Tommy makes a sound. dog.bark(); // Own method // Outputs: Tommy barks!

4. Getters & Setters

Allow you to define methods that are accessed like normal properties, using get and set.

class Person { constructor(first, last) { this.first = first; this.last = last; } get fullName() { return this.first + " " + this.last; } set fullName(value) { [this.first, this.last] = value.split(" "); } } let p = new Person("Amit", "Sharma"); console.log(p.fullName); // Outputs: "Amit Sharma" p.fullName = "Rahul Verma"; console.log(p.first); // Outputs: "Rahul"

5. Static Methods

Methods called on the class itself, not on instances. Use the static keyword.

class MathUtils { static add(a, b) { return a + b; } } console.log(MathUtils.add(5, 3)); // Outputs: 8 // Cannot call on an instance: MathUtils.add is a class method.

23. JSON (JavaScript Object Notation)

JSON is a lightweight data format used to store and exchange data between a server and a browser. It looks like a JavaScript object, but all keys must be in double quotes.

1. JSON.parse()

Converts a JSON string into a JavaScript object.

let jsonString = '{"name": "Noor", "age": 22}'; let userObj = JSON.parse(jsonString); console.log(userObj.name); // Outputs: "Noor" console.log(userObj.age); // Outputs: 22

2. JSON.stringify()

Converts a JavaScript object into a JSON string. Useful when sending data to a server or saving to localStorage.

let user = { name: "Noor", age: 22, city: "Delhi" }; let jsonString = JSON.stringify(user); console.log(jsonString); // Outputs: {"name": "Noor","age":22,"city":"Delhi"} console.log(typeof jsonString); // Outputs: "string"

3. Working with Arrays of Objects

JSON commonly contains arrays of objects (like API responses).

let students = [ { name: "Noor", grade: "A" }, { name: "Rahul", grade: "B" } ]; let json = JSON.stringify(students); // Convert to JSON let back = JSON.parse(json); // Convert back to array console.log(back[0].name); // Outputs: "Noor"

24. Web Storage (LocalStorage & SessionStorage)

The browser lets you save data on the user's computer so it survives page reloads. There are two types: localStorage (stays forever) and sessionStorage (cleared when the tab closes).

1. Setting & Getting Data

Use setItem to save and getItem to read.

// Save data localStorage.setItem("username", "Noor"); localStorage.setItem("theme", "dark"); // Read data console.log(localStorage.getItem("username")); // Outputs: "Noor" console.log(localStorage.getItem("theme")); // Outputs: "dark"

2. Storing Objects (JSON)

localStorage can only store strings, so convert objects with JSON.stringify() and parse them back.

let user = { name: "Noor", age: 22 }; localStorage.setItem("user", JSON.stringify(user)); let savedUser = JSON.parse(localStorage.getItem("user")); console.log(savedUser.name); // Outputs: "Noor"

3. Removing & Clearing Data

localStorage.removeItem("theme"); // Remove one key localStorage.clear(); // Remove EVERYTHING console.log(localStorage.length); // Number of items stored

4. Session Storage

Same API, but data is cleared when the browser tab is closed.

sessionStorage.setItem("sessionId", "abc123"); console.log(sessionStorage.getItem("sessionId")); // Outputs: "abc123"

25. Timers (setTimeout & setInterval)

Timers allow you to run code after a delay or at regular intervals. Time is measured in milliseconds (1000 ms = 1 second).

1. setTimeout() — Run Once After a Delay

setTimeout(function() { console.log("This runs after 2 seconds."); }, 2000); // 2000 ms = 2 seconds

2. setInterval() — Run Repeatedly

Runs the function every X milliseconds until stopped.

let counter = 0; let interval = setInterval(function() { counter++; console.log("Tick:", counter); if (counter === 3) { clearInterval(interval); // Stop after 3 ticks } }, 1000);

3. clearTimeout()

Cancels a pending setTimeout before it runs.

let timer = setTimeout(function() { console.log("This will NOT run."); }, 5000); clearTimeout(timer); // Cancels it immediately

26. Promises & Async/Await

A Promise represents a value that may be available now, later, or never. It is used for asynchronous tasks like fetching data from a server. Async/Await is a cleaner, more readable way to work with promises.

1. Creating & Using a Promise

A promise is created with new Promise() and takes a function with resolve (success) and reject (failure). Consume it with .then() and .catch().

let myPromise = new Promise(function(resolve, reject) { let success = true; if (success) { resolve("Data loaded!"); } else { reject("Something went wrong."); } }); myPromise .then(function(message) { console.log("Success:", message); // Runs if resolved }) .catch(function(error) { console.log("Error:", error); // Runs if rejected });

2. Async/Await

Mark a function with async and use await to pause until the promise settles. Wrap in try...catch for errors.

async function fetchData() { try { let response = await myPromise; // Waits until resolved/rejected console.log("Await Result:", response); } catch (error) { console.log("Await Error:", error); } } fetchData();

3. Promise States

A promise is always in one of three states:

// 1. Pending — Still waiting (initial state) // 2. Fulfilled — Successfully resolved, .then() runs // 3. Rejected — Failed, .catch() runs

27. Fetch API (Working with Servers)

fetch() is the modern way to request data from a server (APIs). It returns a Promise, so you handle it with .then() or async/await.

1. Basic GET Request

Fetches data from a URL. First await response.json(), then use the data.

fetch("https://jsonplaceholder.typicode.com/users/1") .then(function(response) { return response.json(); // Convert to JSON }) .then(function(data) { console.log("User Name:", data.name); }) .catch(function(error) { console.log("Fetch Error:", error); });

2. Fetch with Async/Await

async function getUser() { try { let response = await fetch("https://jsonplaceholder.typicode.com/users/1"); let user = await response.json(); console.log("User Email:", user.email); } catch (error) { console.log("Error:", error); } } getUser();

3. Checking Response Status

fetch() only rejects on network errors. Check response.ok or response.status for HTTP errors (like 404).

async function checkApi() { let response = await fetch("https://jsonplaceholder.typicode.com/users/999"); if (response.ok) { console.log("Success! Status:", response.status); } else { console.log("HTTP Error! Status:", response.status); // e.g., 404 } } checkApi();
