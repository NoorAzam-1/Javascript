JavaScript Complete Reference Guide

1. Introduction to JS

JavaScript is a High-level, Dynamically-typed, and Interpreted programming language.

High Level

Easy for humans to understand and write. Memory management is handled automatically. Example: Using simple keywords like if (x > 10) { ... } else { ... }.

Dynamically-typed

Smart enough to understand data types automatically without explicitly declaring them. Types can change at runtime. Example:

let num = 5; // Automatically treated as a Number (Not a String)

Interpreted

The code is executed line-by-line (synchronously) by the browser's JS engine, rather than requiring a separate compilation step beforehand.

2. Variables

Variables are containers for storing data values. JS uses three main keywords to declare them:

1. var

The older way to declare variables. It is function-scoped and can be re-declared and updated.

var x = 10; var x = 20; // Allowed: Re-declared without errors

2. let

The modern way to declare variables. It is block-scoped (lives only inside {}) and can be updated, but cannot be re-declared in the same scope.

let score = 90; score = 95; // Allowed: Updated value // let score = 100; // Error: Cannot re-declare

3. const

Short for constant. It is block-scoped and cannot be updated or re-declared. It must be initialized when declared. Note: If a const is an Object or Array, you cannot re-assign the whole object/array, but you CAN change its internal properties/elements.

const PI = 3.14159; // PI = 3; // Error: Assignment to constant variable const student = { name: "Noor" }; student.name = "Rahul"; // Allowed: Modifying existing property // student = {}; // Error: Cannot re-assign object

3. Data Types

Data types specify the classification of data that a variable can hold in JavaScript. They are broadly divided into Primitive (7 types) and Non-Primitive (Object) types.

1. String

Represents textual data. Must be wrapped in single or double quotes.

let name = "Noor"; let city = 'Delhi';

2. Number

Represents both integer and floating-point (decimal) numbers.

let age = 25; let price = 99.99;

3. Boolean

Represents a logical entity and can have only two values: true or false.

let isJsFun = true; let isGraduated = false;

4. Undefined

A variable that has been declared but has not yet been assigned a value.

let userData; console.log(userData); // Outputs: undefined

5. Null

Represents the intentional absence of any object value.

let emptyValue = null;

6. BigInt (NEW)

Used for extremely large integers that the Number type cannot safely represent. Created by appending n to the end of an integer.

let bigNum = 9007199254740991n; let anotherBig = BigInt(12345678901234567890);

7. Symbol (NEW)

Guarantees a completely unique identifier. Mostly used internally by JS or for adding hidden/unique properties to objects.

let id = Symbol("123"); let id2 = Symbol("123"); console.log(id === id2); // Outputs: false (Always unique)

Non-Primitive: Object (Reference Types)

Used to store collections of data. Note: In JS, Arrays and Functions are technically special types of Objects.

let student = { firstName: "Noor", age: 22 }; // Object let arr = [1, 2, 3]; // Array (is an Object) function greet(){} // Function (is an Object)

4. Operators

1. Arithmetic Operators

Used to perform mathematical calculations.

let sum = 10 + 5; // Addition (+) -> 15 let diff = 10 - 5; // Subtraction (-) -> 5 let product = 10 * 5; // Multiplication (*) -> 50 let quotient = 10 / 5; // Division (/) -> 2 let remainder = 10 % 3; // Modulus (%) -> 1 let power = 2 ** 3; // Exponentiation (**) -> 8

2. Assignment Operators

Used to assign values to variables.

let x = 10; // Simple assignment (=) x += 5; // Equivalent to: x = x + 5 (Result: 15) x -= 3; // Equivalent to: x = x - 3 (Result: 12)

3. Comparison Operators

Used to compare two values and return a boolean (true/false).

5 == "5"; // True (Loose equality: Compares values only, converts type) 5 === "5"; // False (Strict equality: Compares both value AND data type) 10 > 5; // True (Greater than) 10 != 5; // True (Not equal to)

4. Logical Operators

Used to determine the logic between variables or values.

// Logical AND (&&): Both conditions must be true -> (5 > 3 && 10 > 20) returns false // Logical OR (||): At least one condition must be true -> (5 > 3 || 10 > 20) returns true // Logical NOT (!): Reverses the boolean result -> !(5 > 3) returns false

5. Ternary (Conditional) Operator

Acts as a shortcut for an if...else statement.

Syntax: condition ? value_if_true : value_if_false;

let userAge = 18; let status = (userAge >= 18) ? "Adult" : "Minor"; console.log(status); // Outputs: "Adult"

6. Nullish Coalescing Operator (??) (NEW)

Returns its right-hand side operand when its left-hand side is exactly null or undefined. It is similar to || but treats 0 and "" as valid values.

let userScore = 0; let finalScore1 = userScore || 10; // 10 (because 0 is falsy for ||) let finalScore2 = userScore ?? 10; // 0 (because 0 is NOT null/undefined)

5. Type Conversion (Type Casting)

Converting one data type to another. This can be Explicit (done manually by developer) or Implicit (done automatically by JS).

1. Explicit Conversion

let strNum = "50"; let num = Number(strNum); // Converts string to number: 50 let bool = Boolean(1); // Converts to true, Boolean(0) is false let str = String(100); // Converts number to string: "100" let parsed = parseInt("20 years"); // Extracts number: 20

2. Implicit Coercion

JS automatically converts types when using operators like + or -.

console.log("5" + 1); // "51" (Number converted to String) console.log("5" - 1); // 4 (String converted to Number) console.log(true + 1); // 2 (true converted to 1)

6. Conditional Statements

Used to execute different actions based on different conditions.

1. if Statement

let age = 20; if (age >= 18) { console.log("You can vote."); }

2. if...else Statement

let isRaining = false; if (isRaining) { console.log("Take an umbrella."); } else { console.log("Enjoy the sunny day!"); }

3. Else-if Ladder

let marks = 75; if (marks >= 90) { console.log("Grade: A+"); } else if (marks >= 75) { console.log("Grade: A"); } else { console.log("Grade: F"); }

4. Switch Statement

Note: break terminates the switch block.

let dayNumber = 2; switch (dayNumber) { case 1: console.log("Monday"); break; case 2: console.log("Tuesday"); break; default: console.log("Invalid Day"); }

7. Loops

Loops are used to run the same block of code over and over again.

1. for Loop

for (let i = 1; i <= 5; i++) { console.log("Number: " + i); }

2. while Loop

let count = 1; while (count <= 3) { console.log("Count is: " + count); count++; }

3. do...while Loop

Executes the code block once before checking the condition.

let x = 10; do { console.log("Runs at least once!"); x++; } while (x < 5);

4. for...of Loop

Loops through the values of an iterable (Array, String).

let fruits = ["Apple", "Banana"]; for (let fruit of fruits) { console.log(fruit); }

5. for...in Loop

Loops through the keys of an Object.

let car = { brand: "Tata", model: "Nexon" }; for (let key in car) { console.log(key + ": " + car[key]); }

6. break & continue (NEW)

break completely exits the loop. continue skips the current iteration and moves to the next one.

for (let i = 1; i <= 5; i++) { if (i === 3) continue; // Skips printing 3 if (i === 5) break; // Stops loop at 5 console.log(i); // Outputs: 1, 2, 4 }

8. Functions

A reusable block of code designed to perform a specific task.

1. Function Declaration vs Expression

Declaration is hoisted (can be called before defining). Expression is NOT hoisted.

// Declaration function sayHello() { console.log("Hello!"); } // Expression const sayBye = function() { console.log("Bye!"); };

2. Arrow Function (ES6)

Shorter syntax. Does not have its own this context. If one parameter, parentheses optional. If one return statement, curly braces optional.

const square = (num) => { return num * num; }; const doubleIt = n => n * 2; // Implicit return

3. Default Parameters (NEW)

Allows parameters to have pre-set values if no argument is passed.

function greetUser(name = "Guest") { console.log("Hello, " + name); } greetUser(); // Outputs: Hello, Guest greetUser("Noor"); // Outputs: Hello, Noor

4. Rest Parameters (NEW)

Allows a function to accept an indefinite number of arguments as an array, using ....

function calculateSum(...numbers) { return numbers.reduce((acc, curr) => acc + curr, 0); } console.log(calculateSum(1, 2, 3, 4)); // Outputs: 10

9. ES6+ Modern Features

1. Template Literals

String interpolation using backticks `` ` `` instead of quotes. Allows variables and expressions inside ${} and multi-line strings without \n.

let name = "Noor"; let msg = `Hello, ${name}! 2 + 2 equals ${2 + 2}`; console.log(msg); // Outputs: // Hello, Noor! // 2 + 2 equals 4

2. Destructuring (Arrays)

Unpacking values from arrays into distinct variables based on their position (index).

let colors = ["Red", "Green", "Blue"]; let [firstColor, secondColor, thirdColor] = colors; console.log(firstColor); // Outputs: Red // Skipping values let [a, , c] = colors; // a="Red", c="Blue"

3. Destructuring (Objects)

Unpacking properties from objects. Variable names must exactly match the property names.

let user = { name: "Rahul", age: 25, city: "Delhi" }; let { name, age } = user; console.log(age); // Outputs: 25 // Renaming variables while destructuring let { name: userName, city: userCity } = user; console.log(userName); // Outputs: Rahul

4. Spread Operator (...)

Expands an iterable (array/object/string) into individual elements. Used for cloning and merging.

let arr1 = [1, 2, 3]; let arr2 = [4, 5, 6]; let merged = [...arr1, ...arr2]; // [1, 2, 3, 4, 5, 6] // Cloning an array (creates a new array, not a reference) let cloneArr = [...arr1];

10. Arrays

An array is a single variable used to store multiple values in an ordered list. Zero-indexed.

1. Creating, Accessing, Modifying

let fruits = ["Mango", "Banana", "Grapes"]; console.log(fruits[0]); // "Mango" fruits[1] = "Apple"; // Modifying

2. Adding & Removing Elements

let items = ["Pen", "Book"]; items.push("Eraser"); // Adds to end -> ["Pen", "Book", "Eraser"] items.unshift("Scale"); // Adds to start -> ["Scale", "Pen", "Book", "Eraser"] items.pop(); // Removes from end -> ["Scale", "Pen", "Book"] items.shift(); // Removes from start -> ["Pen", "Book"]

11. Array Methods

Built-in functions to perform operations without writing manual loops.

1. indexOf() & includes()

let arr = [10, 20, 30]; arr.indexOf(20); // 1 (Returns -1 if not found) arr.includes(20); // true

2. join() & concat()

let words = ["Hello", "World"]; words.join(" - "); // "Hello - World" let merged = [1,2].concat([3,4]); // [1,2,3,4]

3. slice() vs splice()

slice does NOT modify original. splice MODIFIES original.

let nums = [10, 20, 30, 40, 50]; nums.slice(1, 3); // Returns [20, 30] (original unchanged) let arr = ["A", "B", "C", "D"]; arr.splice(1, 2); // Removes 2 items from index 1. arr becomes ["A", "D"] // Splice to INSERT without deleting arr.splice(1, 0, "X", "Y"); // Inserts "X","Y" at index 1. arr becomes ["A", "X", "Y", "D"]

4. sort() & reverse()

Both MODIFY the original array. Sort defaults to string sorting.

let numArr = [40, 100, 1, 5]; numArr.sort((a, b) => a - b); // Ascending: [1, 5, 40, 100] numArr.reverse(); // Descending

5. map(), filter(), reduce() (Most Important)

let prices = [100, 200, 300]; // map: Transform every element (returns new array) let discounted = prices.map(p => p - 20); // [80, 180, 280] // filter: Keep elements that pass test (returns new array) let expensive = prices.filter(p => p > 150); // [200, 300] // reduce: Reduce array to a single value (sum, max, etc.) let total = prices.reduce((acc, curr) => acc + curr, 0); // 600

6. find(), findIndex(), some(), every()

let users = [{id:1, name:"A"}, {id:2, name:"B"}]; users.find(u => u.id === 2); // {id: 2, name: "B"} users.findIndex(u => u.id === 2); // 1 let marks = [80, 90, 45]; marks.every(m => m > 50); // false (all must pass) marks.some(m => m > 50); // true (at least one must pass)

7. forEach() & flat()

let chars = ["a", "b"]; chars.forEach((c, i) => console.log(i + ":" + c)); // Just loops, returns undefined let nested = [1, [2, 3], [4, [5]]]; nested.flat(Infinity); // [1, 2, 3, 4, 5] JS Complete Class Notes

let str = "Hello World Hello"; str.length; // 17 str.indexOf("World"); // 6 str.lastIndexOf("Hello"); // 12 str.includes("World"); // true str.slice(0, 5); // "Hello" (end excluded) str.substring(6, 11); // "World" (same as slice but doesn't accept negatives)

let msg = "I love cats. Cats are cute."; msg.replace("cats", "dogs"); // "I love dogs. Cats are cute." (only first occurrence) msg.replaceAll("cats", "dogs"); // "I love dogs. Dogs are cute." (all occurrences) msg.split(" "); // ["I", "love", "cats.", "Cats", "are", " cute."]

16. JSON (JavaScript Object Notation)

JSON is a text format for storing and transporting data. It looks exactly like a JS Object, but keys and string values MUST be in double quotes. Essential for APIs.

// 1. JSON.stringify() -> Converts JS Object to JSON String let userObj = { name: "Noor", age: 22 }; let jsonString = JSON.stringify(userObj); // Result: '{"name":"Noor","age":22}' (Can be sent to a server) // 2. JSON.parse() -> Converts JSON String back to JS Object let data = '{"name":"Rahul","city":"Delhi"}'; let parsedObj = JSON.parse(data); console.log(parsedObj.city); // Outputs: Delhi

17. DOM Manipulation

DOM (Document Object Model) is a tree-like structure created by the browser. JS uses it to select, modify, add, and remove HTML elements dynamically.

1. Selecting Elements

// Returns a SINGLE element document.getElementById("main-title"); document.querySelector(".btn-primary"); // First match // Returns MULTIPLE elements document.getElementsByClassName("card"); // Live HTMLCollection document.getElementsByTagName("p"); // Live HTMLCollection document.querySelectorAll(".list-item"); // Static NodeList (Recommended for multiple)

2. Reading & Changing Content

let box = document.getElementById("box"); box.innerHTML = "<strong>Hello</strong>"; // Parses HTML tags box.textContent = "Plain Text"; // Safe, ignores HTML tags box.innerText = "Visible Text"; // Respects CSS (won't read hidden text)

3. Changing Attributes & Styles

let img = document.querySelector("img"); img.setAttribute("src", "new.jpg"); // Set img.getAttribute("src"); // Get img.removeAttribute("alt"); // Remove let card = document.querySelector(".card"); card.style.backgroundColor = "red"; // Inline CSS (camelCase)

4. Working with Classes (classList)

let btn = document.querySelector("button"); btn.classList.add("active", "rounded"); btn.classList.remove("rounded"); btn.classList.toggle("active"); // Add if missing, remove if present btn.classList.contains("active"); // true/false btn.classList.replace("old", "new");

5. Creating & Removing Elements

let p = document.createElement("p"); p.textContent = "New Paragraph"; document.body.appendChild(p); // Add as last child let old = document.querySelector(".old"); old.remove(); // Modern way to delete

7. Data Attributes (dataset) (COMPLETED)

Data attributes (data-*) let you store custom info in HTML. Access via dataset. Note: kebab-case in HTML becomes camelCase in JS.

<!-- HTML --> <div id="user" data-userid="101" data-user-role="admin"></div> <!-- JS --> let div = document.getElementById("user"); console.log(div.dataset.userid); // "101" console.log(div.dataset.userRole); // "admin" (user-role became userRole)

18. Event Handling

Events are actions that happen in the browser (clicks, typing, hovering). JS listens for these to make pages interactive.

1. addEventListener

The standard way to attach events. Syntax: element.addEventListener(event, callback).

let btn = document.querySelector("#myBtn"); btn.addEventListener("click", function() { alert("Button clicked!"); }); // Arrow function version btn.addEventListener("mouseover", () => { btn.style.color = "red"; });

2. The Event Object (`e`)

Every event handler automatically receives an event object containing details about what happened.

let input = document.querySelector("input"); input.addEventListener("keydown", function(e) { console.log("Key pressed: " + e.key); // e.g., "a", "Enter" console.log(e.target); // The element that triggered the event });

3. e.preventDefault()

Stops the browser's default behavior. Most commonly used on forms to prevent page reload.

let form = document.querySelector("form"); form.addEventListener("submit", function(e) { e.preventDefault(); // Stops page from reloading! // Now you can get input values and process them via JS let val = document.querySelector("input").value; console.log("Form submitted with: " + val); });

4. Event Delegation

If you have many child elements (e.g., 100 list items), instead of adding 100 event listeners, add ONE listener to the parent. Events "bubble up" from child to parent.

<ul id="parent-list"> <li>Item 1</li> <li>Item 2</li> <li>Item 3</li> </ul> document.getElementById("parent-list").addEventListener("click", function(e) { // Check if the clicked element (e.target) is an <li> if (e.target.tagName === "LI") { console.log("Clicked on: " + e.target.textContent); } });

19. Error Handling (try...catch...finally)

Used to handle runtime errors gracefully without breaking the entire script execution.

try { // Code that might throw an error let data = JSON.parse("This is not valid JSON"); } catch (error) { // Executes ONLY if an error occurs in the try block console.log("An error caught!"); console.log(error.name); // e.g., "SyntaxError" console.log(error.message); // Detailed error text } finally { // Executes ALWAYS, whether there was an error or not console.log("This block always runs."); }

20. Asynchronous JavaScript

JS is single-threaded (executes one line at a time). Async programming allows JS to handle long tasks (like fetching data from a database) in the background without freezing the UI.

1. Timers

// setTimeout: Runs ONCE after a specified delay (in milliseconds) console.log("1"); setTimeout(function() { console.log("3"); // Runs after 2 seconds }, 2000); console.log("2"); // Order of output: 1, 2, 3 // setInterval: Runs repeatedly at an interval let count = 0; let timerId = setInterval(function() { count++; console.log("Tick: " + count); if(count === 3) { clearInterval(timerId); // Must be stopped manually } }, 1000);

2. Callbacks

A function passed as an argument to another function, to be executed later after an async task finishes.

function fetchData(callback) { setTimeout(function() { let data = "Server Data Fetched"; callback(data); // Execute the passed function with the data }, 1000); } fetchData(function(result) { console.log(result); // "Server Data Fetched" after 1 sec });

3. Promises

A cleaner way to handle async operations than callbacks. A promise represents a value that may be available now, later, or never. It has 3 states: Pending, Fulfilled, Rejected.

// Creating a Promise let myPromise = new Promise(function(resolve, reject) { let success = true; if (success) { resolve("Data fetched successfully!"); // On success } else { reject("Network Error occurred!"); // On failure } }); // Consuming a Promise myPromise .then(function(result) { console.log(result); // Runs if resolved }) .catch(function(error) { console.log(error); // Runs if rejected });

4. Async / Await (Modern way to write Promises)

Syntactic sugar over Promises. Makes async code look synchronous and easier to read. await can only be used inside an async function.

async function getUserData() { try { // Code pauses here until myPromise resolves or rejects let result = await myPromise; console.log(result); } catch (error) { console.log(error); } } getUserData();

21. Object-Oriented Programming (OOP)

1. Constructor Functions

Before ES6, blueprints for objects were made using functions. Use the new keyword.

function Person(name, age) { this.name = name; this.age = age; this.greet = function() { console.log(`Hi, I am ${this.name}`); }; } let p1 = new Person("Noor", 22); let p2 = new Person("Rahul", 25); p1.greet(); // "Hi, I am Noor"

2. Prototypes

Adding methods directly inside the constructor wastes memory (every object gets its own copy). Instead, add methods to the prototype so all objects share one copy.

Person.prototype.sleep = function() { console.log(this.name + " is sleeping."); }; p1.sleep(); // "Noor is sleeping."

3. ES6 Classes

A cleaner, modern syntax over constructor functions and prototypes (under the hood, it still uses prototypes).

class Animal { constructor(name) { this.name = name; } speak() { console.log(this.name + " makes a noise."); } } // Inheritance using 'extends' class Dog extends Animal { speak() { console.log(this.name + " barks."); // Overriding parent method } } let dog1 = new Dog("Rex"); dog1.speak(); // "Rex barks."

22. Web Storage (Local & Session Storage)

Allows saving key-value pairs directly in the browser. Data survives page reloads. Only strings can be stored (objects must be JSON.stringified).

1. localStorage

Data persists FOREVER until manually cleared by the user or code.

localStorage.setItem("username", "Noor"); // Save data let user = localStorage.getItem("username"); // Read data console.log(user); // "Noor" // Storing an Object let settings = { theme: "dark", lang: "en" }; localStorage.setItem("settings", JSON.stringify(settings)); let retrieved = JSON.parse(localStorage.getItem("settings")); localStorage.removeItem("username"); // Delete one item localStorage.clear(); // Delete ALL items

2. sessionStorage

Exact same syntax as localStorage, BUT data is automatically cleared as soon as the user closes the specific browser tab.

sessionStorage.setItem("token", "abc123xyz"); let token = sessionStorage.getItem("token");
